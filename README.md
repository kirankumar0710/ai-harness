# ai-harness

A collection of AI agent projects. Each folder is a self-contained project
with its own code, tests, demos, packaging and README.

| Project | What it is |
|---|---|
| [`odysseus/`](odysseus/) | A small agent harness that works with any model vendor (Gemini, OpenAI, OpenRouter, Anthropic). Based on the original Odysseus harness from <https://odysseus-harness.vercel.app/>, restructured and made vendor-agnostic. |

To get started with a project, `cd` into its folder (for example
`cd odysseus`) and follow the README there. Commands such as
`pip install -e .` must be run from the project folder, not from this root.
